# 《智能应用开发》课程大纲（示例文档）

## 课程简介

本课程面向软件工程专业本科生，系统讲授基于大语言模型（LLM）的智能应用开发技术。课程涵盖提示工程、LangChain 框架、检索增强生成（RAG）、Agent 智能体、大模型微调与部署等核心内容。

## 考核方式

课程总评成绩由三部分构成：

- 平时作业与课堂表现：占 30%
- 期中项目：占 20%
- 期末大作业：占 50%

期末大作业要求：基于 LangChain 框架、在线大模型或离线大模型，开发一款完整的智能应用，并提交应用源代码仓库（GitHub/Gitee）与 README 说明文档。

## 第七章：智能应用开发

本章学习目标：

1. 理解 RAG（检索增强生成）的基本原理与适用场景；
2. 掌握 LangChain 的核心模块：模型 I/O（Model I/O）、检索（Retrieval）、链（Chains）、记忆（Memory）、代理（Agents）；
3. 能够独立搭建一个"文档问答"智能应用；
4. 了解向量数据库（FAISS、Chroma 等）的工作机制。

### RAG 的基本流程

RAG 的标准流程分为离线与在线两个阶段。离线阶段：收集文档 → 文本切分（Chunking）→ 向量化（Embedding）→ 存入向量数据库。在线阶段：用户提问 → 问题向量化 → 相似度检索 Top-K 相关片段 → 将片段与问题拼入提示词 → 大模型生成答案。

### 为什么需要 RAG

大模型存在知识截止时间、幻觉与私有知识缺失三大问题。RAG 通过"先检索后生成"的方式，让模型基于外部知识库作答，显著降低幻觉、支持私有数据、且无需重新训练模型。

## 常见问题

问：GLM-4-Flash 收费吗？
答：智谱 AI 开放平台的 GLM-4-Flash 模型对开发者免费开放，适合教学与原型开发。

问：向量数据库选哪个？
答：教学场景推荐 FAISS（轻量、本地运行）；生产场景可选 Milvus、Qdrant 等支持分布式部署的方案。
